# Angalamman Blue Metals - Client Project

A modern full-stack web application for **Angalamman Blue Metals** - building materials supplier (Blue metal aggregates, M-Sand, P-Sand, Gravel, Sengal, etc.), fleet booking, price estimation, and admin management portal.

## Features

- **Materials Catalog & Live Calculator**: Instant price calculations for aggregates, sand, bricks, and custom truck loads.
- **Fleet & Tipper Management**: Mini tippers, heavy tippers, tractor trolleys booking and delivery logistics tracking.
- **Order & Quote Booking**: Seamless order placement with instant WhatsApp dispatch notifications.
- **Admin Management Portal**: Real-time management of products, vehicle fleets, inquiries, price updates, and inventory.
- **Fast Modern UI**: Powered by React, Vite, Lucide Icons, and responsive design.
- **Backend API**: Express.js REST API with SQLite database persistence.

## Tech Stack

- **Frontend**: React, Vite, Lucide React, Modern CSS
- **Backend**: Node.js, Express, SQLite3 (better-sqlite3 / sqlite)
- **Logistics**: WhatsApp API integration for dispatch notifications

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run

1. **One-click start (Windows)**:
   Double-click `run.bat` or run:
   ```cmd
   run.bat
   ```

2. **Manual setup**:
   - **Backend**:
     ```bash
     cd backend
     npm install
     npm run dev
     ```
   - **Frontend**:
     ```bash
     cd frontend
     npm install
     npm run dev
     ```
